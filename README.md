# Media Gallery Flutter + Dart Backend

Веб-приложение для отображения и управления медиа (фото, видео, гиф) с главной страницей и админкой.

## Архитектура

- **Frontend**: Flutter Web
- **Backend**: Dart shelf сервер
- **База данных**: PostgreSQL

## Структура проекта

```
flutter_project/
├── frontend/          # Flutter приложение
├── backend/           # Dart shelf сервер
├── database/          # SQL скрипты
├── scripts/           # Вспомогательные скрипты
└── docs/              # Документация
```

## Установка и запуск

### 1. Настройка базы данных PostgreSQL

- Установите PostgreSQL (версия 14+)
- Создайте базу данных:
  ```sql
  CREATE DATABASE media_gallery;
  ```
- Выполните скрипт инициализации:
  ```bash
  psql -U postgres -d media_gallery -f database/init.sql
  ```

### 2. Запуск бэкенда

Перейдите в папку `backend` и установите зависимости:

```bash
cd backend
dart pub get
```

Запустите сервер:

```bash
dart run bin/server.dart
```

Сервер будет доступен по адресу `http://localhost:8080`.

### 3. Запуск фронтенда

Перейдите в папку `frontend` и установите зависимости:

```bash
cd frontend
flutter pub get
```

Запустите веб-приложение:

```bash
flutter run -d chrome
```

Приложение откроется в браузере.

## Функциональность

### Главная страница
- Сетка медиа с фильтрацией по типу (фото, видео, гиф)
- Hover эффект с увеличением и фиолетовой рамкой
- Клик открывает модальное окно (80% экрана)
- Кнопка скачивания в модальном окне

### Админка
- Авторизация (логин/пароль)
- Загрузка новых медиа с предпросмотром
- Просмотр и удаление существующих медиа

### API эндпоинты
- `GET /api/media` – список медиа
- `POST /api/media` – загрузка
- `GET /api/media/{id}/download` – скачивание
- `POST /api/auth/login` – авторизация
