# План реализации веб-приложения на Flutter с бэкендом на Dart

## Обзор
Приложение для отображения и управления медиа (фото, видео, гиф) с главной страницей и админкой.

## Архитектура
- **Frontend**: Flutter (Web) с использованием Dart.
- **Backend**: Dart shelf сервер с PostgreSQL.
- **База данных**: PostgreSQL локально (localhost:5432, пользователь postgres, пароль postgres).

## Структура проекта
См. [architecture.md](architecture.md) для деталей.

## Основные функциональные требования

### 1. Главная страница
- Сетка медиа с тремя блоками (Фото, Видео, Гиф).
- Hover эффект: увеличение карточки + фиолетовая рамка (`#6b28c9`).
- Клик открывает модальное окно (80% ширины и высоты экрана).
- В модальном окне:
  - Полноразмерное отображение медиа.
  - Кнопка "Скачать" внизу по центру.
  - Для видео: элементы управления (пауза, воспроизведение).

### 2. Админка
- Авторизация (логин/пароль).
- Форма загрузки новых медиа (фото, видео, гиф) с предпросмотром.
- Просмотр существующих медиа с возможностью удаления.

### 3. Бэкенд API
- `GET /api/media` – получение списка медиа с фильтрацией по типу.
- `POST /api/media` – загрузка нового медиа (мультипарт форма).
- `GET /api/media/{id}/download` – скачивание файла.
- `POST /api/auth/login` – аутентификация.

### 4. Дизайн и цвета
Используемая палитра:
- `#6b28c9` – primary (фиолетовый)
- `#d91136` – secondary (красный)
- `#cc7212` – accent (оранжевый)
- `#3d9e33` – success (зеленый)
- `#4191b0` – info (синий)
